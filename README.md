# Демонстрация работы API
В проекте показаны самые базовые и простые принципы работы общения клиента и сервера через REST API, с использованием небольшой экспертной системы для выбора направдения отдыха
## Клиент: 
Небольшой класс, который с помощью своих методов и библиотеки requests обращается к серверу, а после, показывает ответ в форме JSON и HTTP код ответа
## Сервер: 
Простейший stateless-сервер, с одним POST, который возвращает наиболее подходящие направления по ответам клиента и GET с query-параметрами, который возвращает вопрос, индекс которого указан в параметре
